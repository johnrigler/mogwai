# The page is a composition

Mogwai can host page layouts and narratives, while DAISY stores individual records. SB Shell supplies filesystem-oriented ordering and navigation.

A page may combine an essay, table, image, PDF and directory listing without merging their source files.

- Content lives in files or directories.
- A manifest decides what appears and in what order.
- Tables reference JSON or CSV rather than embedding all rows in HTML.
- Print and screen are alternative renderings of the same material.
