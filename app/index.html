Install or update on phone or Chromebook
  1. Open this page in Chrome and confirm 0.3.0 appears at the top. Use Update app for a fresh online load.
  2. Choose Install Mogwai, or use Chrome’s menu to install this app.
  3. From an app's system share menu, choose Mogwai.
Updating keeps the current receipt and prepared text in this window. YouTube’s social-network panel is its own menu. Installing Mogwai does not add a button to that panel. The test above opens system sharing directly where supported.
